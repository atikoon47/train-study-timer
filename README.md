## 🌟 จุดเด่นและแนวคิด (Concept)
เปลี่ยนการอ่านหนังสือให้เป็นการเดินทางสุดคลาสสิกด้วยรถไฟไทย:
- **ซื้อตั๋ว** = ตั้งเป้าหมายการอ่าน (วิชา, ระยะเวลา, ชั้นโดยสาร)
- **ฉีกตั๋วออกเดินทาง** = ลากฉีกใบย้อยของตั๋ว (Stub) ด้วย Pointer Events หรือกดปุ่ม เพื่อเริ่มนับเวลา
- **รถไฟวิ่ง** = ตัวจับเวลา Minimalist พร้อมหัวรถไฟวิ่งตามระยะทางบนรางแบบเรียลไทม์ และบอกชื่อสถานีที่กำลังผ่าน
- **ถึงสถานี** = อ่านครบตามเวลา ได้รับการประทับตรา "ตรวจตั๋วแล้ว" และปลดล็อกตราประทับสถานีลงสมุดพาสปอร์ตการรถไฟ
- **แปลงเวลาเป็นระยะทาง** = อ่าน 60 นาที = วิ่ง 30 กม. (1 นาที = 0.5 กม.)

## 📱 หน้าจอและการทำงาน (Features)
1. **หน้าซื้อตั๋ว (Buy Ticket)**:
   - ป้อนชื่อวิชา/หนังสือ พร้อมรายการวิชาที่เคยใช้ให้เลือกซ้ำสะดวกรวดเร็ว
   - เลือกระยะเวลา: 15 / 25 (Pomodoro) / 50 / 90 นาที หรือกรอกเวลากำหนดเอง
   - เลือกชั้นโดยสาร: ชั้น 3 (ธรรมดา), ชั้น 2 (ปรับอากาศ), ชั้น 1 (ตู้นอน Pomodoro)
   - แสดงตั๋วจำลองแบบเรียลไทม์: เลขขบวนสุ่ม, ที่นั่ง, เวลาออก-ถึง, รอยปรุ และรอยเว้าขอบตั๋วสไตล์ตั๋วแข็ง รฟท.
2. **การฉีกตั๋วเพื่อเริ่ม (Tear to Depart)**:
   - ลากใบย้อยของตั๋วด้วยทัชสกรีนหรือเมาส์ หากลากเกิน ~60% ใบย้อยจะปลิวออกพร้อมเสียงฉีกกระดาษสังเคราะห์และแรงสั่น Haptic Vibration
   - หากลากไม่ถึง 60% จะเด้งกลับ (Spring back)
   - มีปุ่มทางเลือก "ฉีกตั๋วเพื่อเริ่มออกเดินทาง" สำหรับผู้ใช้เดสก์ท็อปและผู้ที่ตั้งค่า `prefers-reduced-motion`
3. **หน้าจับเวลา (Minimalist Reading Timer)**:
   - ตัวเลขนับถอยหลังขนาดใหญ่ Tabular Numbers ชัดเจน ไม่ดึงสายตา
   - เส้นทางมินิ SVG แสดงหัวรถไฟกำลังเคลื่อนที่ พร้อมระบุสถานี/จุดตรวจที่กำลังเคลื่อนผ่าน
   - รองรับ **Screen Wake Lock API** ป้องกันหน้าจอดับขณะกำลังจดจ่ออ่านหนังสือ
   - ปุ่มขอยกเลิกขบวนรถ (ต้องกดยืนยันก่อน โดยตั๋วจะถูกประทับตราหรือขาดครึ่งใบ และไม่ได้รับระยะทาง)
4. **หน้าถึงสถานี (Station Arrival)**:
   - เสียงระฆังสถานีรถไฟสังเคราะห์ (Web Audio API) และ Web Notification แจ้งเตือน
   - แอนิเมชันประทับตรา "ตรวจตั๋วแล้ว" กระแทกลงบนตั๋ว
   - หากระยะทางสะสมเดินทางผ่านสถานีสำคัญ จะปลดล็อกตราประทับประจำสถานี
5. **ผังเส้นทางรถไฟ (Schematic Transit Map)**:
   - แผนผัง SVG สไตล์ Transit Diagram (BTS/MRT) แสดงจุดสถานี, กิโลเมตร, และหัวรถไฟตามตำแหน่งสะสมจริง
   - สายหลักเริ่มต้น: **สายเหนือ (กรุงเทพ - เชียงใหม่ 751 กม.)** พร้อมรองรับสายอีสานและสายใต้
   - สามารถคลิกที่สถานีเพื่อดูรายละเอียดและประวัติย่อได้
6. **สมุดสะสมตราประทับ (Railway Passport Stamps)**:
   - ตราประทับวงกลมสไตล์ Eki Stamp ของสถานีต่างๆ (อยุธยา, ลพบุรี, นครสวรรค์, พิษณุโลก, ลำปาง, เชียงใหม่ ฯลฯ)
   - สถานีที่ยังไปไม่ถึงจะแสดงระยะทางที่ต้องอ่านเพิ่ม
7. **สถิติและการจัดการข้อมูล (Statistics & Data Tools)**:
   - เวลาอ่านรวมวันนี้ / สัปดาห์นี้, ระยะทางสะสมรวม (กม.), Streak วันที่อ่านต่อเนื่อง
   - ประวัติเที่ยวอ่านหนังสือย้อนหลัง
   - สำรองข้อมูล (Export JSON), นำเข้าข้อมูล (Import JSON), และรีเซ็ตข้อมูล

## 🛠️ สถาปัตยกรรมทางเทคนิค (Technical Architecture)
- **Vanilla Web Technologies**: HTML5 + CSS3 + Modern JavaScript (ES6+) ไม่ใช้ Framework หรือ Library ภายนอก
- **No External API / 100% Free**: ไม่มีการเรียก API นอก, โฮสต์บน **GitHub Pages**, **Cloudflare Pages**, หรือ **Netlify** ได้ทันที
- **Safe Persistence**: ห่อหุ้ม `localStorage` ด้วย `try/catch` ทุกจุด พร้อม Memory Fallback เมื่ออยู่ในโหมด Private Browsing
- **Accurate Timestamp Timer**: ใช้ `endTime = Date.now() + durationMs` คำนวณเวลาคงเหลือจริงจาก Date.now() เสมอ ป้องกันเวลาเพี้ยนเมื่อสลับแท็บ (`visibilitychange`) หรือปิด-เปิดเบราว์เซอร์ใหม่
- **Synthesized Web Audio API**: สังเคราะห์เสียงฉีกกระดาษ, หวูดรถไฟ, ระฆังสถานี, และเสียงประทับตราด้วยโค้ด JavaScript ล้วน ไม่ต้องดาวน์โหลดไฟล์ MP3 ทำงานได้ออฟไลน์ 100%
- **Offline PWA Support**: มี `sw.js` (Service Worker) และ `manifest.json` สามารถติดตั้งลงหน้าจอหลักของมือถือ (Add to Home Screen) ได้
- **Responsive**: ออกแบบ Mobile-first ใช้งานได้อย่างสมบูรณ์แบบบนหน้าจอตั้งแต่ 360px จนถึง Desktop

## 🚀 วิธีเปิดใช้งาน (Getting Started)
เปิดไฟล์ `index.html` บนเบราว์เซอร์ใดก็ได้ หรือรัน Local Server:

```bash
# ตัวอย่างการรันด้วย Python
python -m http.server 8000

# หรือด้วย Node.js
npx serve .
```

เข้าใช้งานได้ทันทีที่: `http://localhost:8000`
