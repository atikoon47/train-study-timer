# ตั๋วอ่านหนังสือ

ตัวจับเวลาอ่านหนังสือแบบนั่งรถไฟ เลือกสถานีต้นทางและปลายทาง เลือกขบวน ฉีกตั๋ว แล้วอ่านไปเรื่อยๆ จนรถถึงสถานี

## วิธีใช้

1. **ต้นทาง**: ครั้งแรกเริ่มที่กรุงเทพอภิวัฒน์ หลังจากนั้นจะเริ่มจากสถานีที่ลงรถครั้งล่าสุด
2. **ปลายทาง**: แตะสถานีบนแผนที่ หรือกดช่องปลายทางเพื่อค้นหา ถ้าข้ามสายจะผ่านชุมทาง
3. **เลือกขบวน**: เวลาอ่านคิดจากระยะทาง ขบวนยิ่งเร็วยิ่งใช้เวลาน้อย

   | ขบวน | กม. ต่อนาที |
   |---|---|
   | ด่วนพิเศษ | 8 |
   | ด่วน | 6 |
   | เร็ว | 4 |
   | ธรรมดา | 3 |

4. **ฉีกตั๋ว**: ลากส่วนล่างของตั๋วลง หรือกดปุ่ม เพื่อเริ่มจับเวลา
5. **ระหว่างทาง**: กล้องแผนที่ตามขบวนรถไปตามเส้นทาง ใกล้ถึงสถานีจะมีป้ายสถานีแบบไทยขึ้นมา กด "วิวหน้าต่าง" เพื่อมองออกนอกหน้าต่างตู้โดยสาร ฉากเปลี่ยนตามภาค (ภาคกลางทุ่งนากับเจดีย์ ภาคเหนือภูเขาและอุโมงค์ขุนตาน อีสานทุ่งกว้างกับบ้านใต้ถุนสูง ภาคใต้ทะเล สวนยาง และเขาหินปูน)
6. **ลงกลางทาง**: ลงได้ที่สถานีล่าสุดที่ผ่านมาแล้ว เวลาที่อ่านไปแล้วจะถูกบันทึกไว้ และเที่ยวหน้าจะออกจากสถานีนั้น
7. **พักที่สถานี**: ถึงแล้วกด "พักที่สถานี 5 นาที" เพื่อพักระหว่างรอบ (แบบ Pomodoro) ครบเวลามีเสียงเตือน แล้วค่อยขึ้นขบวนต่อไป
8. **สมุดเดินทาง**: ดูเวลาอ่าน 7 วันล่าสุดและแยกตามวิชา สะสมตราประทับทุกสถานีที่เคยลง และบนแผนที่มีเส้นจุดสีทองบอกเส้นทางที่เคยนั่งแล้ว

มี 5 สาย 45 สถานี: สายเหนือ (ถึงเชียงใหม่) สายตะวันออกเฉียงเหนือ (ถึงหนองคาย) สายใต้ (ถึงสุไหงโก-ลก) สายน้ำตก (ข้ามสะพานแม่น้ำแควถึงน้ำตก) และสายตะวันออก (ถึงอรัญประเทศ)

ระยะทางและพิกัดสถานีเป็นค่าโดยประมาณ เส้นทางบนแผนที่ลากตรงระหว่างสถานี

แผนที่ใช้ [MapLibre GL](https://maplibre.org) กับแผนที่ฟรีจาก [OpenFreeMap](https://openfreemap.org) (ข้อมูล © OpenStreetMap) จึงต้องต่ออินเทอร์เน็ต ถ้าออฟไลน์ แอปจะใช้รายการสถานีกับวิวหน้าต่างแทน

## เปิดใช้งาน

```bash
python -m http.server 8124
```

แล้วเปิด http://localhost:8124

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `js/rail.js` | ข้อมูลสถานี/สาย การหาเส้นทาง และการคำนวณขบวน (ไม่มี DOM) |
| `js/store.js` | เก็บข้อมูลใน localStorage และคำนวณสถิติ ใช้วันที่ตามเวลาเครื่อง |
| `js/map.js` | แผนที่จริง หมุดสถานี เส้นทาง และกล้องตามรถ |
| `js/scene.js` | วิวหน้าต่าง: ฉากรถไฟวิ่งแบบ parallax |
| `js/ticket.js` | ตั๋วแบบ pass และระบบลากฉีก |
| `js/sound.js` | เสียงสังเคราะห์ด้วย Web Audio |
| `js/app.js` | ลำดับหน้าจอทั้งหมด |

## ทดสอบ

```bash
node tests/run.js
```
